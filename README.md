# goal_tracker
A responsive goal tracker app that let users create their own gaols, edit, pause/resume and complete their goals in a funny way.
used MUI for theme and style,and i18next for language. hope enjoy the app.☺️

 feature:
 
🌸Dashboard: 
  ✨ shows your level,xp,streak,goals,completed and completion percentage.
  📊chart ---> weekly activity and categories
   every goal you create appear here.
   
Goal card:
1. progress button (complete step by step (till your target )
2. pause/resume button 
3. complete action button (complete your goal)
4. edit button (edit your title, category or target )
5. details button (more info about your card )
6. delete icon
   🍀 Each card shows:
   1. title
   2.category
   3.status
   4.progressbar

🌸Goals:
1.Filter goals
2.All goals
3.Active goals
4.Paused goals
5.Completed goals
6.Archive goals


🌸Create Goal:
title + categoty + target


🌸Achievements:

 🍀unlock:
1 goal = "first goal"
5 goals = "goal master"

 🍀completion:
1 goal = "first completed"
10 goals = "goal crusher"

 🍀xp:
100 xp = level 2
each progress = 10 xp
500 xp = level 5

 🍀streak:
7 days streak
30 days streak
100 days streak


🌸 settings:

🍀 light and dark mode

🍀theme color

🍀language:
persian + english
rtl + ltr
direction changes for each language
stable ui

🍀backuup:
export data
import data
reset all data
